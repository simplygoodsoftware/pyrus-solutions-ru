# КЭДО

Кадровые документы, расчётные листки и отпуска с обменом данными с 1С:ЗУП.

## Установка

[Установите CLI и подключитесь к Pyrus](../../README.md), затем выполните из корня репозитория:

```powershell
pyrus validate .\solutions\kedo\bundle.pyrus.yaml
pyrus publish .\solutions\kedo\bundle.pyrus.yaml --dry-run
pyrus publish .\solutions\kedo\bundle.pyrus.yaml
```

Выполняйте команды по очереди. Если пробная публикация сообщает об ошибке, устраните её перед установкой. Исключение — непроверенные ссылки на ещё не созданные формы сотрудников: см. [ограничения первой установки](../../README.md#пока-не-реализовано).

## Установленные формы

Решение устанавливает формы «Кадровые документы», «Расчетный листок» и «Отпуск», а также формы для хранения данных сотрудников:

- «Карточка физлица» — ФИО, СНИЛС и другие персональные данные.
- «Карточка сотрудника» — сведения об отдельном трудоустройстве.

Если карточки уже установлены другим решением, используются существующие формы. Кадровые документы и отпуск связаны с карточкой сотрудника, расчётный листок — с карточкой физлица.

## Настройка после установки

1. Выдайте сотрудникам доступ к задачам КЭДО, с которыми они будут работать, а учётной записи расширения 1С:ЗУП — к формам КЭДО, карточкам физлиц и сотрудников.
2. Заполните реквизиты организаций и назначьте руководителей подразделений в оргструктуре — руководитель согласует отпуск.
3. Проверьте, что в реестре кадровых форм организации выбраны установленные формы «Кадровые документы», «Карточка сотрудника», «Расчетный листок» и «Отпуск». Формы «Карточка физлица» и «Карточка сотрудника» находятся в папке «Pyrus — Сотрудники», остальные формы — в «Pyrus КЭДО v2».
4. Укажите в расширении 1С:ЗУП идентификаторы форм из результата публикации.
5. В настройках форм включите используемые интеграции: КриптоПро, ПЭП и эскалации.

## Ограничения

### Пока не реализовано

- Подписание кадровых документов через Госключ.
- Автоматический перенос задач из прежних кадровых форм в новую модель.

### Особенности работы

- Публикация заполняет пустые ячейки кадрового реестра. Уже выбранные формы заменяются вручную.
- Новые интеграции создаются выключенными.
