# КЭДО

Кадровые документы, расчётные листки и отпуска с обменом данными с 1С:ЗУП. Карточка физлица хранит ФИО и СНИЛС, карточка сотрудника — отдельное трудоустройство. Кадровые документы и отпуск связаны с трудоустройством, расчётный листок — с физлицом.

## Установка

[Установите CLI и подключитесь к Pyrus](../../README.md), затем выполните из корня репозитория:

```powershell
pyrus validate .\solutions\kedo\bundle.pyrus.yaml
pyrus publish .\solutions\kedo\bundle.pyrus.yaml --unlisted keep --dry-run
pyrus publish .\solutions\kedo\bundle.pyrus.yaml --unlisted keep
```

Выполняйте команды по очереди. Если пробная публикация сообщает об ошибке, устраните её перед установкой. Исключение — непроверенные ссылки на ещё не созданные зависимости: см. [ограничения](../../README.md#ограничения).

## Настройка после установки

1. Выдайте сотрудникам доступ к задачам КЭДО, с которыми они будут работать, а учётной записи расширения 1С:ЗУП — к формам КЭДО, карточкам физлиц и сотрудников.
2. Заполните реквизиты организаций и колонку «Руководитель отдела» в оргструктуре — руководитель согласует отпуск.
3. В реестре кадровых форм организации выберите установленные формы. Формы «Карточка физлица» и «Карточка сотрудника» находятся в папке «Pyrus — Сотрудники», остальные формы — в «Pyrus КЭДО v2».
4. Укажите в расширении 1С:ЗУП идентификаторы форм из результата публикации.
5. В настройках форм включите используемые интеграции: КриптоПро, ПЭП и эскалации.

## Ограничения

### Пока не реализовано

- Подписание кадровых документов через Госключ: требуется доработка получения ФИО и СНИЛС по цепочке «документ → карточка сотрудника → карточка физлица». После неё интеграция будет добавлена в бандл.
- Синхронизация отпусков через `/v4/vacations` для этой модели. API ищет СНИЛС непосредственно в карточке сотрудника, а здесь он хранится в карточке физлица.
- Отдельная ячейка карточки физлица в кадровом реестре.
- Автоматический перенос задач из прежних кадровых форм в новую модель.

### Особенности работы

- Публикация заполняет пустые ячейки кадрового реестра. Уже выбранные формы заменяются вручную.
- Новые интеграции создаются выключенными.
